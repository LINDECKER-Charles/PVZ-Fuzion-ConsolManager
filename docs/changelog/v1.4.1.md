Patch release adapting the toolkit to the new `travel_buffs.json` layout shipped by the game, `{
category: { id: { name, desc } } }`, while keeping the legacy `{ category: { id: value } }` layout
working. Missing travel buffs are now detected by `category:id` presence (the contents of
`name`/`desc` are not compared once an ID exists in the target locale), and every consumer — the
Markdown report, `travel_buffs_diff.json`, the Trello CSV export, the `Dumps/` migration and the
duplicate checker — carries the complete nested object instead of a flattened string. The same
commit bumps the package to 1.4.1; a follow-up commit removes the French release notes that had been
committed under `docs/`.

## Fixed

- Travel buff diffing now understands the game's current `travel_buffs.json` format `{ category: {
  id: { name, desc } } }`. `diffTravelBuffs()` (`src/parsers/strings.ts`) no longer goes through the
  generic flattened `diffNestedFile()` path: it loads both locale files, walks the source category
  by category and reports an entry only when the `id` is absent from the target locale's category
  (`Object.hasOwn`), so a partially translated `{ name: "", desc: "..." }` entry that already exists
  in the target is not flagged. Each result is a new `TravelBuffEntry` (`src/core/models.ts`,
  extends `StringEntry` with `category`, `id`, `raw: unknown` and a fixed `status: "missing"`);
  `source` is taken from `raw.name` for the new format or from the string leaf for the legacy `{
  category: { id: value } }` format, which remains supported.
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))
- `missing_travel_buffs.md` (`buildTravelBuffsReport()` in `src/reporting/markdown.ts`) is no longer
  a flat key/value table produced by `writeFlatReport()`: it now prints a `> **Missing IDs:** N`
  header and a single fenced JSON block rebuilding `{ category: { id: { name, desc } } }` from the
  `raw` objects, so the full untranslated entry is visible to translators. As before, no file is
  written when there are no missing IDs.
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))
- `travel_buffs_diff.json` (`buildTravelBuffsDiff()` in `src/reporting/diff-json.ts`) is rebuilt
  from `entry.category` / `entry.id` / `entry.raw` instead of splitting the compound key on its
  first `:` and emitting `source` strings; the output therefore keeps the complete `{ name, desc }`
  object per missing ID and stays directly reusable as a locale file. The previous `""` category
  fallback for keys without a `:` is gone.
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))
- Trello export: travel buffs get their own `travelBuffCards()` builder in
  `src/tools/trello-export.ts` (list `LIST_TRAVEL = "Travel Buffs"`), replacing the generic
  `stringCards()` path. The card name is `entry.source` (`raw.name`, falling back to the
  `category:id` key) and the description is a fenced JSON block of `{ [category]: { [id]: raw } }`,
  both truncated to the existing `NAME_MAX_LEN` / `DESCRIPTION_MAX_LEN` limits — previously the card
  only carried the flattened string value.
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))
- Migration from `Dumps/travel_buffs.json` (`extractNested()` in `src/tools/migration.ts`) now
  recurses into nested objects and records the full leaf path (`[category, id, "name"]`, `[category,
  id, "desc"]`), so the generated locale file preserves the `{ category: { id: { name, desc } } }`
  tree; empty or non-string leaves are skipped. Legacy two-level dumps still migrate as before.
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))
- Duplicate checker: `flattenNested()` is now recursive and collapses any nesting depth to
  colon-delimited paths (`advancedBuffs:0:name`, `advancedBuffs:0:desc`), so value-duplicate
  detection on `travel_buffs.json` covers the new format's `name`/`desc` fields. Non-object
  top-level values are still skipped.
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))

## Docs

- `README.md`: the features list and the troubleshooting row for `advancedBuffs:0`-style keys now
  describe presence checking by `category:id` and the preservation of the full `{ name, desc }`
  object, replacing the description of the old flattening behaviour.
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))
- `docs/release-notes.md` (French release notes for v1.4.1, added by the fix commit) was removed
  from the repository; release notes are to be kept local only. The only `.gitignore` change is a
  trailing newline after the existing `*.tgz` pattern (`release.md` was already ignored before this
  commit).
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49),
  [`6444e36`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/6444e36))

## Internal

- `flattenNested()` was de-duplicated: the copy in `src/tools/duplicate-checker.ts` was deleted and
  the module now re-exports the single implementation from `src/parsers/strings.ts`.
  `diffNestedFile()` remains exported from `src/parsers/strings.ts` but no longer has an in-tree
  caller after this change.
  ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))
- Tests added/updated for the new format across `tests/parsers/strings.test.ts`,
  `tests/reporting/diff-json.test.ts`, `tests/reporting/markdown.test.ts`,
  `tests/tools/duplicate-checker.test.ts`, `tests/tools/migration.test.ts` and
  `tests/tools/trello-export.test.ts` (+150/-14 lines; the Trello test now drives `collectCards()`
  directly and filters on the `Travel Buffs` list). The removed release notes stated 172 passing
  tests. ([`f5e6d49`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/f5e6d49))
