v1.7.0 makes the CLI drivable by AI agents and CI. Every tool now runs headlessly — `diff`,
`duplicates`, `trello`, `migrate-tips`, `migrate-levels` and `pr-resume` — with a global `--help`
(`-h`, also per command), `--version`, `--project-root <dir>` (one run, never saved) and `--json`
(one `{ok, command, result|error}` document on stdout, warnings on stderr). Usage errors exit with
code 2, and without a command and without a TTY the interactive console now refuses to start
(exit 2) instead of hanging. The npm package ships an Agent Skill (`skills/pvzf-console/SKILL.md`)
and the console gains a main-menu entry `[5] AI agents` that detects the coding agents on the
machine, shows which already have the skill and installs it for the ticked ones, globally or for
the current folder; it relies on the new runtime dependency `skills` (vercel-labs/skills), which
requires Node.js 22.20+ and is loaded lazily, with a printed `npx skills add …` command as the
fallback. The repository gains a tracked `AGENTS.md`, `CLAUDE.md` is tracked and imports it, and
the landing page publishes an `llms.txt`. The documentation set is updated to match.

The range also carries the work that landed on main after v1.6.0: a public landing page (`site/`)
with an interactive replica of the console and its GitHub Pages workflow, the README cut down to a
front page backed by a `docs/` set (guides, internals, release notes, this changelog),
`CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`, a weekly Dependabot schedule, and three batches of
Dependabot updates (CodeQL action, `@clack/prompts` 1.8.1, dev tooling). vitest is bumped to 4.1.12
for two `@vitest/mocker` advisories and held on 4.x while Node 20 is supported.

## Added

- Headless mode for every tool, replacing the two-command parser of 1.6.0. New commands, all
  accepting the global options below: `pvzf-console diff --lang LOCALE [--out DIR] [--with-diff]`
  (existing, now with the global options), `duplicates --lang LOCALE [--out DIR]`,
  `trello --lang LOCALE [--out DIR]`, `migrate-tips --lang LOCALE`,
  `migrate-levels --lang LOCALE` and `pr-resume [--input FILE] [--output FILE]` (existing).
  `--lang` is required and case-sensitive; `--out` defaults to `reports/` (`diff`, `duplicates`)
  or `exports/` (`trello`). Locale-taking commands reject an unknown locale with the list of
  available ones, and `diff`, `trello`, `migrate-tips` and `migrate-levels` also reject the source
  locale. Migrations never overwrite an existing file. [`af9638c`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/af9638c)
- Global options and entry points: `--project-root <dir>` replaces the configured game folder for
  one run (held in memory, never written to the settings; validated for the commands that read the
  game files), `--json` prints exactly one document on stdout — `{ok: true, command, result}` on
  success, `{ok: false, command, error: {message, exitCode}}` on failure — `--help` / `-h` shows
  the program help or, after a command, that command's help (it wins over the command's other
  arguments), and `--version` prints the version read from the shipped `package.json`. Exit codes:
  `0` success, `1` runtime failure, `2` usage error, unknown locale or invalid project root.
  Warnings go to stderr in headless runs so stdout stays parseable. [`af9638c`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/af9638c)
- The `diff` result now carries the missing count of each category (`categories`, `totalMissing`,
  `reportsDir`, `jsonDiff` under `--json`), through the new `scanLocale` in `src/tools/scan.ts`.
  [`af9638c`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/af9638c)
- New `src/cli/headless/` layer driven by a command registry (`registry.ts`, one `HeadlessCommand`
  record per command in `commands/`: `diff.ts`, `duplicates.ts`, `migrate.ts`, `trello.ts`,
  `pr-resume.ts`, plus `out-option.ts`): the parser (`parser.ts`), the help screens (`help.ts`),
  the dispatch (`runner.ts`), the shared locale checks (`locale-target.ts`) and the version lookup
  (`version.ts`) all read the same records, so adding a command is one registry entry. [`af9638c`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/af9638c)
- Agent Skill `skills/pvzf-console/SKILL.md` (Agent Skills standard), shipped in the npm tarball
  (`files` in `package.json` gains `skills/`). It tells an agent to always pass a command and
  `--json`, how to point the CLI at `PvZ_Fusion_Translator/` with `--project-root`, and what each
  command does. [`6b044a3`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/6b044a3)
- New runtime dependency `skills` ^1.8.1 (vercel-labs/skills) and `src/tools/agent-skills/`:
  `gateway.ts` (the `AgentSkillsGateway` port: `detectAgents`, `installSkill`, scopes `global` /
  `project`), `skills-library.ts` (implementation over the library, loaded with a dynamic
  `import("skills")` only when Node.js is 22.20 or newer; installs in `copy` mode with
  `lockfile: false` and `telemetry: false`) and `bundled-skill.ts` (the skill folder inside the
  package, and the shell fallback `npx skills add LINDECKER-Charles/PVZ-Fuzion-ConsolManager --skill
  pvzf-console`). Installing from the bundled folder gives each agent the skill that matches the
  installed CLI version and needs no network access. [`6b044a3`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/6b044a3)
- New main-menu entry `[5] AI agents` (`src/cli/screens/agents.ts`, hint "install the skill for
  Claude Code, Codex…"): asks for the scope (*Every project* or *This folder only*), lists the
  detected agents with `installed` / `not installed`, offers a multi-select (agents missing the
  skill pre-ticked, all ticked when none is missing so the screen doubles as an update), installs
  and prints one line per agent, then reminds that open agent sessions must be restarted. When the
  installer cannot run (Node.js older than 22.20, library failing to load, no agent detected,
  installation error) it prints the reason and the `npx skills add …` command instead. [`a16f757`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/a16f757)
- New `askMultiSelect` prompt (`CheckboxOption`, `@clack/prompts` `multiselect`, at least one row
  required, `null` on cancel) in `src/cli/menus.ts`, exposed on `AppDeps`. [`a16f757`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/a16f757)

- Interactive console demo (`site/src/terminal/`): autoplay loops over four scripted scenarios —
  `diff`, `migrate`, `trello`, `pr` (labelled pr-resume) — selectable from chips and from the tool

  under 20 ms). Clicking the screen with a non-touch pointer, or pressing one of the handled keys,

## Changed

- Without a command, the console starts only when stdin and stdout are TTYs; otherwise it prints
  `error: the interactive console needs a terminal (stdin and stdout must be a TTY).` plus a
  pointer to `--help` and exits 2, where 1.6.0 started clack's prompts anyway, rendered the first
  menu and exited on EOF in a pipe, a CI step or an agent's shell. `MainOptions` gains
  `isInteractiveTerminal` for tests. [`af9638c`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/af9638c)
- Argument errors keep the argparse style of 1.6.0 (`error: unrecognized arguments: …`,
  `error: argument --x: expected one argument`, now also `error: the following arguments are
  required: --lang` and `error: invalid choice: 'x' (choose from …)`), all with exit code 2.
  [`af9638c`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/af9638c)
- Main menu is now `[1] Show what's missing`, `[2] Translator tools`, `[3] Documentation`,
  `[4] Settings`, `[5] AI agents`, `Exit`. [`a16f757`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/a16f757)
- `.gitignore` stops ignoring `CLAUDE.md`. The commit scope map gains `skills/**` → `skills` and
  `site/**` → `site`, and files `README*.md`, `CONTRIBUTING.md`, `AGENTS.md`, `CLAUDE.md`, `docs/**`
  under `docs` and `tsup*.config.ts` under `infra` (in `AGENTS.md` and the table of
  `CONTRIBUTING.md`). [`c579cb4`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/c579cb4)
- `README.md` no longer carries the whole manual (597 lines removed): it is now a front page — Quick
  start, What it does, Using the console, Using it headlessly, Where things land, Documentation,
  Security, Contributing, Credits, License — linking to `docs/` and `CONTRIBUTING.md`. The commit
  body states the old README had drifted from the code. [`4df68ca`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/4df68ca)
- `.gitignore` stops ignoring `docs` wholesale; only the working material stays local, now under
  the gitignored `docs/archived/` (release drafts, Discord announcement, dated audits), which
  replaces the four file-level ignore rules. [`4df68ca`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/4df68ca), [`5d89f81`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/5d89f81)
- `README.dist.md` (npm README): the 'Migrate tips & buffs' paragraph is rewritten to match current
  behaviour — keys come from the raw `Dumps/`, each value is looked up in the locale's own
  `translation_strings.json`, untranslated entries are left out with a `Created tips_iz.json —
  128/402 translated` result line, and an existing file is never overwritten (the previous text
  described an all-or-nothing rebuild from the legacy file). It now points to `CONTRIBUTING.md` and
  `docs/` instead of the repo README. [`4df68ca`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/4df68ca)
- Dependabot checks npm and github-actions updates weekly instead of monthly
  (`.github/dependabot.yml`, same 05:00 Europe/Paris slot, same PR limits); the cooldown is
  unchanged and still does the soaking — the weekly schedule only bounds how long an already-cleared
  version waits before being proposed. README badge (`dependabot-weekly + cooldown`) and
  `SECURITY.md` updated accordingly. [`6c9713c`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/6c9713c)
- `npm run typecheck` now also runs `tsc --noEmit -p site/tsconfig.json`; `site/tsconfig.json`
  extends the root config with `lib: [ES2022, DOM, DOM.Iterable]`, `types: []` (no Node types) and
  `include: [src]`. [`b98459d`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/b98459d)
- `docs/` sorted by audience and purpose: the user pages move to `docs/guide/` (`usage`,
  `configuration`, `catalog`, `outputs`, `troubleshooting`), `architecture.md` to `docs/internals/`,
  and every link (root README, CONTRIBUTING, the landing page, cross-references) follows. The
