1.4.0 replaces the Python engine (and its Node wrapper that spawned a `.pyz` zipapp) with a full
TypeScript rewrite bundled by tsup into a single ESM `dist/cli.js`; the only runtime requirement is
now Node >= 20 and the package ships zero runtime dependencies. The interactive TUI, the `diff
--lang <LOCALE> [--out DIR] [--with-diff]` command, the `settings.json` format (snake_case keys),
the four-location `PvZ_Fusion_Translator/` discovery and the report/CSV outputs are preserved. The
migration tool is reworked: it now writes partial results instead of skipping a file when any source
string is untranslated, covers `abyss_buffs.json` and `travel_buffs.json`, and gains a second tool
that builds the custom-level files (`customlevel_strings.json`, `customlevel_regexs.json`,
`custom_level_data.json`). The release also sets up the project's security tooling (Dependabot,
CodeQL, npm audit, ESLint security ruleset, Semgrep, gitleaks) and absorbs the first Dependabot PRs
(#1, #3, #5, #6), one of which broke `npm ci` until vitest was aligned with @vitest/coverage-v8 v4.

## Added

- New Translator tool `[2] Migrate custom levels — customlevel_strings/regexs/custom_level_data`
  (`migrateCustomLevels` in `src/tools/migration.ts`): creates `customlevel_strings.json`,
  `customlevel_regexs.json` and `custom_level_data.json` under `Localization/<locale>/Strings/`.
  Because `Dumps/` has no complete source for these files, the key set is taken from the configured
  source locale (default `English`) while the values are looked up in the target locale's
  `translation_strings.json` (for `custom_level_data.json` the `name` and `startTip` fields of each
  level are translated).
  ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))
- The tips migration tool (now `[1] Migrate tips & buffs —
  tips_iz/tips_fs/abyss_buffs/travel_buffs`, `migrateTipsAndBuffs`) additionally generates
  `abyss_buffs.json` (from `Dumps/AbyssBuffData.json`, non-empty `infos[*].name` / `introduce`,
  keyed by the Chinese string itself) and `travel_buffs.json` (two-level category → key nesting
  preserved from `Dumps/travel_buffs.json`), alongside `tips_iz.json` and `tips_fs.json`.
  ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))
- Per-file migration report in the TUI: each target is listed as `Created <file> — n/m translated`
  (with an `(empty — run a diff to list missing entries)` hint when nothing was translated yet), `↷
  Skipped <file> (already present)` or `Skipped <file> (no source found)`; the result model
  (`FileMigrationResult`) exposes `status: created | skippedExists | sourceMissing` plus `migrated`
  / `available` counts.
  ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))

## Changed

- Engine rewritten from Python to TypeScript (strict, ESM, Node >= 20). Layout: `src/cli.ts` (entry,
  shebang injected by tsup) → `src/cli/app.ts` (class `App` holding settings/reports root with an
  injectable `AppDeps` bundle of UI helpers, replacing the pytest monkeypatch seam),
  `src/cli/{banner,menus,theme}.ts` (`ConsoleIO` abstraction, ANSI theme, Windows VT100 enablement),
  `src/config.ts` / `src/settings.ts`, `src/core/{models,diff}.ts`,
  `src/parsers/{loaders,almanac,strings}.ts` (incl. the `Dumps` source mode, `isDumpsSource`),
  `src/reporting/{markdown,diff-json,trello-csv}.ts`,
  `src/tools/{migration,trello-export,duplicate-checker}.ts`. Main menu (Show what's missing /
  Translator tools / Settings), the nine Settings entries and the `diff --lang <LOCALE> [--out DIR]
  [--with-diff]` CLI are kept; argv parsing is hand-rolled (`parseCliArgs`, `CliArgError`) to mimic
  the former argparse messages (`error: argument --lang: expected one argument`, `error:
  unrecognized arguments: …`).
  ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))
- Translator Tools menu grows from three to four entries: `[1] Migrate tips & buffs`, `[2] Migrate
  custom levels`, `[3] Export Trello CSV` (was `[2]`), `[4] Check duplicates` (was `[3]`). The
  warning shown when `tips_iz.json` / `tips_fs.json` is missing now points to `Translator Tools >
  Migrate tips & buffs`.
  ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))
- Migration is no longer all-or-nothing. The Python `migrate_tips` refused to write a file if any
  Chinese tip text was missing from `translation_strings.json` (and bailed out entirely when that
  file was empty); the new `runMigration` writes the translated subset — possibly an empty `{}` — so
  the file exists for a later diff to surface the gaps. Existing destination files are still never
  overwritten (that check now runs before the missing-source check); output stays UTF-8 with BOM,
  4-space indented.
  ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))
- `PvZ_Fusion_Translator/` auto-discovery (`discoverProjectRoot` in `src/config.ts`) is ported
  unchanged: the same four non-recursive candidates as the Python `_discover_project_root` (next to
  the install, its parent, the current working directory, its parent), first existing directory
  wins, canonical sibling path otherwise. `REPO_ROOT` is now derived from `import.meta.url` (parent
  of `src/` in dev, of `dist/` once built).
  ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))
- Duplicate-key detection (`detectRawDuplicateKeys` in `src/tools/duplicate-checker.ts`) is
  reimplemented with a strict recursive-descent `JsonScanner` that fires once per closed object,
  reproducing Python's `object_pairs_hook` semantics since `JSON.parse` silently keeps the last
  value. ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))
- `settings.json` keeps its snake_case on-disk keys (`project_root`, `source_locale`, `color`,
  `accent_color`, `density`, `show_emoji`, `show_banner`, `trello_label`) for backward
  compatibility; unknown keys are ignored on load (`FILE_KEYS` filter), unreadable/invalid JSON
  falls back to defaults, and a leading `~` in `project_root` is expanded via `HOME` /
  `USERPROFILE`. The file is still written next to the package root (`REPO_ROOT/settings.json`).
  ([`417b3ef`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/417b3ef))
- `package.json` switched to `"type": "module"`; the `pvzf-console` bin now points to `dist/cli.js`
  instead of `bin/pvzf-console.js`; the published `files` list drops `bin/` and `src/` (ships
  `dist/`, `data/`, both READMEs); scripts replaced by `build` / `prepublishOnly` (tsup), `dev` (tsx
  src/cli.ts), `typecheck` (tsc --noEmit), `test` (vitest run) / `test:cov` (vitest run --coverage).
  ([`9b983e2`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/9b983e2))
- `.gitignore` reworked for the Node toolchain: Python entries (`.venv/`, `venv/`, `build/`,
  `*.egg-info/`, `__pycache__/`, `*.pyc`, `*.pyz`, `.coverage`, `coverage.xml`, `htmlcov/`) and a
  duplicate `dist/` line removed; `.vscode/`, `*.tsbuildinfo`, `docs` and `graphify-out` added.
  ([`9b983e2`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/9b983e2))
- `src/core/models.ts`: `Plant`, `Zombie`, `Achievement` become type aliases of `AlmanacEntry`
  instead of empty extending interfaces (lint-driven).
  ([`a91fbbc`](https://github.com/LINDECKER-Charles/PVZ-Fuzion-ConsolManager/commit/a91fbbc))
