This release focuses on **data integrity, diff usability, and long-term stability** of the toolchain.

---

## 🔍 Duplicate detection tool

A new tool has been introduced to ensure **data consistency across versions**.

* Detects **duplicate entries** within translation datasets
* Helps prevent conflicts and unexpected overrides
* Designed to be fast and usable on large datasets

👉 Useful for:

* Translation QA
* Preventing regression during updates
* Cleaning inconsistent locale files

---

## 📦 JSON diff export

Diff generation has been extended with a new output format:

* In addition to Markdown reports, you can now generate a **JSON diff**
* Provides a **structured list of missing entries**
* Ready to be consumed programmatically or reused in tooling

### Benefits

* Easier automation (pipelines, scripts, external tools)
* Direct integration with other systems
* Cleaner data manipulation compared to Markdown parsing

---

## 🧪 Test suite introduction

A test layer has been added to improve reliability and prevent regressions.

* Covers critical parts of the application
* Ensures stability of:

  * diff logic
  * data processing
  * core behaviors

### Goal

* Prevent future bugs
* Secure refactors
* Enable safer feature iteration

---

## 🧠 Summary

This update strengthens the project on three key axes:

* **Integrity** → duplicate detection
* **Interoperability** → JSON diff export
* **Stability** → test coverage

---

## 📌 Notes

* No breaking changes
* Fully compatible with existing workflows
