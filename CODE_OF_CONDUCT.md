# Code of Conduct

This project exists to help a volunteer translation community. The bar for taking part is
simple: treat people the way you would want to be treated when you are the one asking a
question in a language that is not your first.

## Expected behaviour

- Be respectful and patient, especially with newcomers and non-native speakers.
- Critique the work, not the person. "This key is duplicated" — not "you always break this".
- Assume good faith. Most disagreements here are about translation choices or file formats,
  and both sides usually have a point.
- Accept that the maintainer's time is finite: an unanswered issue is a backlog, not a slight.

## Unacceptable behaviour

- Harassment, insults, or personal attacks, in public or in private.
- Discriminatory language or imagery of any kind.
- Publishing someone else's private information without their explicit permission.
- Deliberately derailing discussions, or repeatedly reopening settled decisions.

## Scope

This applies to every space the project uses: issues, pull requests, commit messages, code
review, and any private channel where project business is conducted.

## Reporting

Report a problem privately to **charles.lindecker@outlook.fr**. Reports are handled
confidentially. The maintainer may edit or remove offending content, and may block a
contributor from the repository when the behaviour continues or when a single incident is
serious enough on its own.

This is a small project with a single maintainer: expect a human response, not a formal
process.
